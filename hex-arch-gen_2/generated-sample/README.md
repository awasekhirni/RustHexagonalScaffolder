# generated-sample

Hexagonal-architecture REST API generated by **hex-gen** from the
PostgreSQL schema `public`.

* HTTP framework: **axum** (async, tokio)
* Persistence: **SQLx** (runtime-checked queries, no ORM)
* API docs: **OpenAPI 3** via utoipa — served at `/swagger-ui`
* Patterns: **Enterprise Bus** (Command/Query) + **Enterprise Repository**

## Run

```bash
cp .env.example .env      # or edit the generated .env directly
cargo run
# Swagger UI  → http://localhost:8080/swagger-ui
# OpenAPI doc → http://localhost:8080/api-docs/openapi.json
```

## Architecture

```
api/ (handlers, dto)          inbound adapters  →  enterprise bus
application/ (services)       use-cases         →  domain ports
domain/ (entities, ports)     the hexagon core (no framework deps)
infrastructure/ (SQLx)        outbound adapters ←  domain ports
enterprise/ (bus, repository) shared patterns
```

Every write goes through the `CommandBus`, every read through the
`QueryBus`; services depend only on domain port traits, so the SQLx
adapters are swappable without touching business logic.

## Regeneration

Edit the schema, re-run the generator with `--force`, and the artefacts
are refreshed. Manual edits inside generated files will be lost —
extend the generator templates instead.
